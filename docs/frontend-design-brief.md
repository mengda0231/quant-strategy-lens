# Quant Strategy Lens Frontend Brief

- `page_type`: local multi-strategy research dashboard
- `target_user`: quant researcher reviewing phase-1 strategy baselines
- `core_task`: compare all strategies quickly, then drill into one strategy's equity, trades, signals, notes, and representative samples
- `required_modules`:
  - overview hero with latest run context
  - strategy comparison cards
  - research leaderboard and comparison table
  - detail route for one strategy
  - equity chart, trades table, signals table, notes panel, representative samples panel
- `visual_direction`: editorial lab meets data dashboard, with warm-paper background, dark ink typography, deep green accent, and restrained burnished orange highlights
- `interaction_focus`: fast switching between overview and strategy detail, scan-first metrics, responsive tables with horizontal overflow
- `responsive_requirements`:
  - desktop: sticky side rail + split content columns
  - tablet: stacked cards and compressed metrics grid
  - mobile: one-column reading flow, sticky top navigation, scrollable data tables
